# Hus Language Support

Hus Language extension for Visual Studio Code, providing syntax highlighting and built-in code interpretation.

## Features
- **Syntax Highlighting:** Full color syntax support for `.hus` files.
- **Built-in Interpreter:** Run your Hus code instantly inside VS Code using `Ctrl + F5`.

## Usage
1. Open any `.hus` file.
2. Press `Ctrl + F5` (or run the command `Run Hus File`) to execute your script.
3. View the output in the VS Code Output channel.
